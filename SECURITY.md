# Seguridad

Este repo es un sitio estático de portfolio: no tiene servidor, base de datos, formularios ni credenciales.

- Solo el dueño puede publicar cambios. Las contribuciones externas se revisan antes de aceptarse.
- La página limita qué puede cargar (Content-Security-Policy): archivos propios, Lenis desde jsDelivr (verificado con integridad SRI) y las tipografías de Google.
- No hay secretos en el código. Si encontrás uno, o cualquier problema de seguridad, avisá a avanth.studio@gmail.com en lugar de abrir un issue público.
